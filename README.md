# Truck Katas

Short JavaScript drills for your food truck. A **kata** is a drill you repeat
until it feels easy.

| Kata | Practice |
|---|---|
| 1 | Variables |
| 2 | Functions |
| 3 | Objects (and methods with `this`) |
| 4 | Arrays |
| 5 | JSON |
| 6 | Loops (`for` and `forEach`) |
| 7 | Building the page (`createElement`, cards, clicks) |
| 8 | Fetch (status codes, template literals, GET and POST, `try` / `catch`) |
| 9 | Bootstrap (work in `my-page.html`, not `script.js`) |
| 10 | API tool (requests in Postman or Bruno; you check yourself) |

## How to use it

1. Fork this repo, then clone **your** fork (same steps as `level-2-practice`).
2. Right-click `index.html` → **Open with Live Server**. Pick a kata.
3. Open that kata's `script.js`. Each drill has an **Example**, then **Reps**.
4. Do one rep, save, and look at the page: ✅ passed · ⬜ not started · 🟡 almost · ❌ try again.
5. Save point when a kata is done: `git add .` → `git commit -m "Kata 2 done"` → `git push`

**New katas added?** On GitHub, open your fork → **Sync fork** → **Update branch**. Then in VS Code: **Sync** (or `git pull`).

**Another round?** Copy everything in `start-over.js` and paste it over `script.js`.

Only change `script.js` (in Kata 9, `my-page.html`). The `checks.js` files and `kata-check.js` do the checking. Kata 10 happens in your API tool, and you tick the boxes yourself.
