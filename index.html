Truck Katas

A kata is a short drill you repeat until it feels easy. Each one has an Example, then Reps for you.

Open a kata, then open its script.js in VS Code. Do one rep, save, and check the page. Do them in any order. Start with the one that feels shakiest.

  • Kata 1: Variablesconst, let, text, numbers and true/false
  • Kata 2: FunctionsFunctions that return an answer
  • Kata 3: ObjectsProperties, making objects, and methods with this
  • Kata 4: ArraysLists, indexes, and lists of objects
  • Kata 5: JSONParse, fix, stringify, and catch bad JSON
  • Kata 6: Loopsfor loops that add up, and forEach onto the page (for Friday!)
